# The Panou Fund website

A static Jekyll site built with the Serif theme by Zerostatic. Initiative and giving copy is maintained in Markdown files.

## Pages

- `index.md` — homepage and overview of the three initiatives
- `_initiatives/` — Philoptochos, Ukraine, and Liberty pages
- `giving.md` — how to give through DonorsTrust

## Run locally

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

The site is available at `http://127.0.0.1:4000/`.
