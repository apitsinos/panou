# Panou Fund website

A static Jekyll site using the Serif theme by Zerostatic. Pages are based on the supplied web copy document.

## Local preview

Install Ruby and Bundler, then run:

    bundle install
    bundle exec jekyll serve

Open the local URL printed by Jekyll.

## GitHub Pages

Set the url and baseurl in _config.yml for the chosen repository. For a project site, baseurl is typically /repository-name; for a user or organization site, it is empty. Configure the repository to deploy with GitHub Actions using the Jekyll build workflow.

## Before publishing

Add the preferred contact method and final repository/site URL before publishing.

Theme: zerostaticthemes/jekyll-serif-theme.
